# lib-ctan

The resident library: TeX sources the engine may read at runtime, through the texmf index (`ls-R` and the kpsewhich shim), never through `--path`. Each entry is a CTAN-id directory — or, for files the catalogue has no record for, an archive-named directory (`latex`, `graphics`, `vntex`) filled by `lctan --from` — with `provenance.json` (the lockfile pin: archive, revision, snapshot, hashes) and TDS runfiles under `tex/`. An entry is data the pool consumes, a raw package a binding delegates to, or the source of a native binding; anything else is parked in `lib-park/`. `lctan --index` writes `ls-R`; `lctan --check` is local; `lctan --restore` rebuilds the trees from the committed pins. See `docs/architecture.md` sections 5 and 8.

Corpus-facing entries from the texmf brief are pinned by TeX Live revision and archive SHA-512 in each `provenance.json`. Dated `--snapshot` fetches from texlive.info currently return an Anubis HTML challenge (HTTP 200), so these rows were taken from the live CTAN tlnet mirror. `ifthen` and `latex` share latex.tar.xz revision 79618; `keyval` and `graphics` share graphics.tar.xz revision 79234. `t5enc.def` is a `vntex` member, not a `latex` member.
